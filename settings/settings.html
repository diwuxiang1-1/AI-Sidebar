API 配置

关于 API Key(当前版本实际能力)
  • 可添加多个同一服务商的 API Key。
  • 启用多个 Key 后,请求会按填写顺序轮询(每个启用的 Key 依次尝试)。
  • 当前 Key 请求失败时,会尝试下一个已启用 Key;单次请求每个 Key 最多尝试一次,不会无限重试。
  • 全部 Key 都失败时,返回最后一个真实错误。
  • 被停用的 Key 不参与轮询。
  • 不同服务商的 Key 不会混用:每个服务商有各自的 Key 池,换服务商会切换到对应的池。
  • 轮询位置不写入配置 —— 每次都从第一个启用的 Key 开始。

使用者语言

关于使用者语言
  • 这里设置的是你自己看到的界面语言。
  • 它与「网页翻译」里的目标语言是两件独立的事：界面用中文、翻译成日文，完全可以。
  • 开启「当前网页」聊天时，AI 也会被要求用这个语言回复。

关于 Token 与费用
  • 回复结束后会显示 API 返回的真实用量(输入 / 输出 / 合计)。
  • 如果当前服务商没有返回用量,会明确显示「未提供实际用量」,不会用本地估算冒充。
  • 费用只在服务商直接返回时才显示;拿不到可靠价格时不显示任何金额。
