AI-Sidebar v1.0.0

一个基于 Manifest V3 的 AI 浏览器侧边栏扩展。

AI-Sidebar 允许用户连接自己的 AI API，通过侧边栏与当前网页进行交互，实现网页理解、翻译、文件分析以及部分网页修改能力。

本项目采用 BYOK（Bring Your Own Key）模式：

用户自行提供 API Key
API 请求直接发送至用户选择的 AI 服务商
作者不保存、不收集用户 API Key 和聊天内容
✨ 主要功能
1. AI 网页上下文理解

支持读取当前网页内容，并让 AI 根据网页进行：

网页总结
内容解释
信息提取
问答分析
页面结构分析

例如：

“总结这个网页主要内容”

“告诉我这个页面有哪些重要信息”

“分析这个网页的数据结构”

AI 会基于当前页面内容进行回答。

2. AI 网页翻译

支持网页内容智能翻译。

特点：

支持多语言目标翻译
不只是逐字翻译，而是根据上下文进行语义翻译
尽可能保持原网页结构
适合文章、教程、文档等网页

支持语言包括：

中文
英文
日文
韩文
法文
德文
西班牙文
俄文

使用场景：

外文技术文档阅读
新闻阅读
学术资料阅读
产品说明阅读
3. AI 修改网页（实验功能）

支持通过 AI 对当前网页进行部分修改。

包括：

修改网页样式
修改背景颜色
隐藏网页元素
删除部分图片
删除部分链接
修改文本内容
添加简单网页元素
调整部分页面布局

例如：

“把网页背景改成深色”

“隐藏所有广告图片”

“删除页面中的导航栏”

JS 注入与网页修改说明

AI-Sidebar 使用浏览器 Content Script 对网页进行操作。

部分网站支持：

DOM 修改
CSS 修改
元素隐藏
页面内容调整

但是：

由于浏览器安全机制限制，部分网站可能无法修改。

可能原因：

CSP（Content Security Policy）限制
网站自身安全策略
Shadow DOM
iframe 隔离
动态渲染框架限制

例如：

某些网站禁止：

eval 执行
动态 JavaScript 注入
修改关键页面逻辑

遇到这种情况：

AI-Sidebar 会返回无法执行原因，而不是强制绕过限制。

注意事项
1. API Key 安全

请勿分享自己的 API Key。

建议：

使用独立 API Key
设置额度限制
定期更换 Key
2. AI 修改网页存在限制

由于浏览器安全机制：

部分网站无法修改。

这不是 AI-Sidebar 故障，而是浏览器安全限制。

3. AI 输出结果可能错误

AI 可能：

理解错误网页内容
生成错误修改方案
翻译存在偏差

重要操作请自行确认。
